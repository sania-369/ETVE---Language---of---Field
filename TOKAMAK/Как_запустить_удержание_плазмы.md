# ⚡ Как запустить удержание плазмы в токамаках на резонансных частотах (ETVP 12.3 Stack)

## Цель
Запустить управляемый термоядерный синтез в токамаке, используя **когерентность** (`C`) как управляющий параметр. Система измеряет поле (датчики Bi₂Te₃), калибрует прогнозы (ETVP 12.3) и удерживает плазму через ИИ-агент, дообученный на методах ЕТВЭ.

## ⚙️ 2. КАЛИБРОВКА ПО ITER

Настройте прогнозы удержания для вашего токамака.

### 📊 Скрипт калибровки
[🔗 ETVE_ITER_Coherence_Calibration.py](https://github.com/sania-369/ETVE---Language---of---Field/blob/main/ETVE_ITER_Coherence_Calibration.py)

**Как использовать:**
1. Подставьте параметры вашего токамака в словарь `ITER`.
2. Запустите скрипт, чтобы получить `τ_ETVE` для разных `C`.
3. Интегрируйте калиброванное время удержания в систему управления.

**Связь с ETVP 12.3:**  
Скрипт реализует поправку на когерентность оператора (`C`), которая усиливает удержание при `C > 0.8`.

## 🛡️ 3. ДАТЧИКИ И ЭКРАНИРОВАНИЕ

Установите сенсоры и защиту, чтобы измерять `∇C` и изолировать систему от шума.

### 📡 Меморандум по датчикам
[🔗 ETVE_Bi2Te3_Coherence_Sensor_v1.0.txt](https://github.com/sania-369/ETVE---Language---of---Field/blob/main/ETVE_Bi2Te3_Coherence_Sensor_v1.0.txt)

**Принцип:**  
Тонкая плёнка Bi₂Te₃ преобразует градиент когерентности (`∇C`) в электрический сигнал через нелинейный эффект Холла (NLHE).

**Двухконтурная структура:**
- **Внешний контур (экран):** поглощает внешний шум, защищает систему от декогеренции.
- **Внутренний контур (датчик):** считывает `∇C` плазмы для ИИ-агента.

**Шаги установки:**
1. Нанесите плёнку Bi₂Te₃ на внутреннюю поверхность вакуумной камеры.
2. Подключите СВЧ-генератор (1–10 ГГц) и вольтметр к контактам.
3. Подайте сигнал с датчика на ИИ-контроллер.

## 🧠 3.1. УНИВЕРСАЛЬНЫЙ ИНТЕГРАТОР

Этот скрипт является **главным вычислительным ядром** для любой установки. Он не привязан к ITER, а работает с параметрами любого токамака.

### 📊 Скрипт-интегратор

[🔗 ETVE_Universal_Integrator_v1.0_Operator_Coherent.py](https://github.com/sania-369/ETVE---Language---of---Field/blob/main/ETVE_Universal_Integrator_v1.0_Operator_Coherent.py)

**Что делает:**
- Рассчитывает **резонансную частоту** (`f_res`) для вашей установки на основе `B`, `Ip`, `R`, `ne`.
- Прогнозирует **время удержания** (`Tau_ETVE`) с учётом когерентности оператора (`op_coherence`), используя ту же логику, что и в калибровочном скрипте.
- Выдаёт **статус системы** (`Coherent` / `Fluctuating`), который показывает, готова ли она к запуску.

**Как использовать:**
1. Подставьте данные вашего токамака в список `tokamacs_data`.
2. Задайте уровень когерентности оператора (`focus_level`).
3. Запустите скрипт — он покажет прогноз для вашей установки.
4. Интегрируйте его как модуль в ИИ-агент для расчётов в реальном времени.

**Связь с другими компонентами:**
- Принимает `op_coherence` (аналог `C` из **ETVP 12.3**).
- Использует ту же математику, что и калибровка **ITER**.
- Готов к приёму сигналов с **датчиков Bi₂Te₃**.
- Может служить интерфейсом для **ИИ-агента** на этапе принятия решений.

## 🧠 4. ЗАПУСК УПРАВЛЕНИЯ

Объедините все компоненты в один контур управления.

### 🔄 Процесс в реальном времени
1. **Измерение:** Датчики Bi₂Te₃ считывают `∇C` и `entropy_flux`.
2. **Расчёт:** ИИ-агент вычисляет текущую `C` и прогнозирует `τ_ETVE` по калибровочному скрипту.
3. **Управление:** ИИ корректирует параметры удержания (ток, поля, нагрев) для поддержания резонанса.
4. **Защита:** При росте `entropy_flux` система мягко снижает мощность, предотвращая срыв.

### 🔗 Интеграция с ИИ
- Используйте `ETVECoherenceGradScaler` для стабилизации обучения агента.
- Обучите агент на исторических данных с токамаков и симуляциях ETVP 12.3.

## ✅ 5. ВЕРИФИКАЦИЯ

Проверьте, что система работает.

**Критерии успеха:**
- Время удержания (`τ_ETVE`) превышает базовое (`TAU_IPB98_STANDARD`) при `C > 0.8`.
- Датчики регистрируют рост `C` при входе в резонанс.
- ИИ-агент предотвращает срывы в симуляциях.

**Тестовый сценарий:**
1. Запустите симулятор на основе ETVP 12.3.
2. Сравните прогнозы с реальными данными (если есть доступ).
3. Откалибруйте параметры (порог `C`, коэффициент усиления) под ваш токамак.
